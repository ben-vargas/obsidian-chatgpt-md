# Source Tree Guidance

This directory contains the Obsidian plugin runtime source. Prefer the more specific `AGENTS.md` files in child directories when editing code there.

## Top-level source files

### `main.ts`

Plugin bootstrap only.

- Create the `ServiceContainer` via `ServiceContainer.create(app, plugin)`.
- Register commands through handlers and `CommandRegistrar` where possible.
- Load/migrate settings and initialize background model fetching.
- Keep business logic out of `main.ts`; put behavior in commands, services, utilities, or views.
- On unload, stop active streaming and release Obsidian resources.

### `Constants.ts`

Cross-cutting constants and command IDs.

- Provider IDs live here (`openai`, `openrouter`, `anthropic`, `gemini`, `ollama`, `lmstudio`, `zai`).
- Command IDs live here for stable Obsidian command registration.
- Message-format constants (`role::`, chat divider, comment markers) live here.
- Agent wizard prompt and plugin system message live here.
- Do not put provider registry metadata here unless it is truly cross-cutting; provider wiring belongs in `src/Services/Providers/ProviderRegistry.ts`.

### `__mocks__/`

Jest mocks for external runtime APIs.

- `src/__mocks__/obsidian.ts` mocks Obsidian APIs for tests.
- Keep mocks minimal and deterministic.
- Update mocks only when tests require newly used Obsidian surface area.

## Architectural rules

- `src/core/ServiceContainer.ts` is the only dependency wiring location.
- Commands orchestrate; services own stateful/business behavior; utilities are pure helpers.
- Views render UI and collect user input; avoid provider/tool business logic in views.
- Provider-specific API behavior belongs in `src/Services/Adapters/` and provider metadata/factories in `src/Services/Providers/`.
- Tool execution and approval flows live in `src/Services/ToolService.ts` and related services. Never bypass human approval.

## Validation

Use npm:

```bash
npm run build
npm test -- --runInBand
npm run lint
```

`main.js` is generated by the build and should not be edited by hand.
